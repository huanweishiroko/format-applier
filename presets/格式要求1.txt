# 格式要求1：中文公文风排版 + 文本清理 + 结构预处理（零 LLM 即可解析）
#
# 执行顺序（插件内部固定，全部在“角色识别”之前完成）：
#   ① 文本清理    只删标记与符号，正文文字保留
#   ② 结构预处理  只改段落样式（套 Word 内置“标题 1/2/3…”），一个字都不改
#   ③ 角色绑定    把标题1/标题2/标题/正文等角色映射到下面的字体字号
#
# ── 清理：只在本预设生效 ──────────────────────────────────────────────
# 原文档里常常残留 markdown 标记（# ** ` > - | ~~ --- 等）和无意义符号。
# 下面这一行让插件在排版之前先做一次文本清理。格式要求2 / 格式要求3 以及
# 任何不写“清理：”的要求，文字仍然保证一字不改（插件内部照旧 SHA-256 校验）。
#
#   清理：        可组合下列任一词；写“清理：全部”= 打开全部；写“清理：无”= 关闭
#                 markdown / 不可见字符 / 重复标点 / 空白 / 装饰符号 /
#                 空段落（连续空段落压成 1 个）/ 删除空段落（一个都不留）
#   保留符号：    列出的符号永不当作装饰符号删除
#   删除符号：    额外无条件删除的符号，例如 “删除符号：~^”；不需要就删掉那一行
#
# 各类别做的事（只删标记与符号，正文文字一律保留）：
#   markdown     # 标题 → 标题（并升级为“标题1”）、**粗体** → 粗体、__粗体__、
#                *斜体*、`代码`、~~删除线~~、> 引用、- / 1. 列表符号、
#                [文字](链接) → 文字、![图注](图片)、<http://…>、行内 HTML 标签；
#                | 表格 | 行去掉竖线、| --- | 分隔行整行删除；
#                --- / *** 分隔线、``` 代码围栏行整行删除（围栏内代码原样保留）；
#                # 标题 下面的 === / --- 下划线会把它上面那段提升为标题并删除该行
#    注意：本预设同时开了“编号正则”，所以“1. 平台迁移”这类有序编号会被当成
#          文档编号保留（不再当 markdown 列表符号删掉），交给结构预处理判级。
#  不可见字符   零宽空格 U+200B/200C/200D、BOM、软连字符、双向控制符、U+FFFD
#  重复标点     ，，。。！！、、：： 等压缩为一个；去掉段首尾悬空的 、；：/ |
#                （…… 和 —— 是正式中文标点，保留不动）
#  空白         全角空格与连续空格压缩为一个；去掉每段首尾空白
#  装饰符号     ■□●○◆★☆• 等整段只有符号、连续两个以上、或出现在段首段尾时删除；
#                单个夹在正文里的 · ※ 等保留（人名间隔号、公文标记不受影响）
#  碎片合并     PDF/公式转换留下的短行碎片（C / = / × / O(n ...）合并回同一段；
#                转换器重复导出的公式副本会被去重，真正的标题（样式/加粗/编号）绝不动
#  删除空段落   正文里所有空段落全部删除：段与段之间不再有空行，结尾多余空段也清掉；
#                只有“整篇/整格全是空段”时保留 1 个（Word 要求容器里至少有一段）
#
清理：markdown 不可见字符 重复标点 空白 装饰符号 碎片 删除空段落
保留符号：% ‰ ° ± ℃ ℉ ※

# ── 结构预处理：整段加粗 + 编号正则 + 首段标题 → Word 内置标题样式 ──────
# 在角色绑定之前先跑一遍：把“整段加粗”的段落和以编号开头的段落自动判成
# 标题级别，并套上 Word 内置的“标题 1/2/3…”样式（这样导航窗格、目录、大纲
# 级别都能用）；文档标题则套 Word 内置的“标题（Title）”样式。随后再由下面的
# “标题/标题1/标题2”把黑体字号对齐上去。
#
#   结构预处理：整段加粗 编号正则 首段标题 居中短行
#               整段加粗 = 该段每个非空 run 都是粗体
#               编号正则 = 段首编号，按编号体系判级（可在行尾加“公文编号”/“小数编号”强制）
#               首段标题 = 全文第一个非空段落（且不带编号）就是文档标题 → 套“标题”样式
#                          （原文只有 **加粗标记**、没有真加粗时也照样认，因为清理会先去掉 **）
#               居中短行 = 首段标题没命中时的兜底：在“第一个已判级标题”之前的前 5 段里，
#                          居中且简短、不以句末标点结尾的那一段作为文档标题
#                          标题只会有一个；文档本来就有“标题”样式时两个信号都不动手
#               写“结构预处理：无”= 关闭本模块；只要编号/加粗两项就写
#              “结构预处理：整段加粗 编号正则”
#   判级规则（自动识别文档用的是哪套编号体系）：
#     小数编号（文档里出现 1.1 / 1.1.1）：1. = 1 级，1.1 = 2 级，1.1.1 = 3 级
#     公文编号（默认）：一、= 1 级，（一）= 2 级，1. / 1、= 3 级，（1）/① = 4 级
#     第一章 / 第X部分 = 1 级；整段加粗但没有编号 = 1 级
#   安全阀：超过 60 字的段落、以句末标点结尾的段落、表格里的段落、已有标题样式的
#           段落都不动；整篇都加粗的文档（正文本身就是粗体）会自动忽略“整段加粗”；
#           首段若以编号开头（例如直接以“一、总体情况”开篇）不会当成文档标题。
结构预处理：整段加粗 编号正则 首段标题 居中短行
